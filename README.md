# fivsevn-assets

[fivsevn.com](https://fivsevn.com/) 主页及共用图片：`homepage/` 放主页插图，`avatar/` 放头像，`common/` 放图标，`pages/` 放独立页面素材。现有引用路径保持稳定；本仓库没有发布 Actions。

文章与照片在各内容仓库的发布包中维护：

| 内容 | 仓库 |
|---|---|
| Posts、Fieldlog | [fivsevn-devlog](https://github.com/fivsevn-agy/fivsevn-devlog) |
| Flux | [fivsevn-flux](https://github.com/fivsevn/fivsevn-flux) |
| Savour | [fivsevn-savour](https://github.com/fivsevn/fivsevn-savour) |
| Stills、Motion | [fivsevn-roll](https://github.com/fivsevn/fivsevn-roll) |
| 57store | [fivsevn-57store](https://github.com/fivsevn/fivsevn-57store) |

`post/2025/202504/` 保留四份原始图片。上传入口和操作按对应仓库 README 设置。
